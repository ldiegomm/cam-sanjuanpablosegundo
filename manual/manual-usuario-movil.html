1. Objetivo del manual móvil

Este documento describe el uso del sistema CAM desde un teléfono celular. La aplicación conserva las mismas funciones principales de la versión de escritorio, pero reorganiza la navegación para pantallas pequeñas y prioriza acciones táctiles.

  • Permite consultar el panel diario del centro.
  • Permite buscar pacientes, revisar perfiles, historial y medicamentos.
  • Permite tareas administrativas como usuarios y notificaciones cuando el rol es Administrador.
La interfaz móvil usa una barra de navegación inferior fija y un encabezado compacto con el acceso administrativo.

2. Navegación y estructura en celular

En móvil, el sistema cambia la barra lateral por una barra inferior con accesos directos a Inicio, Adultos, Historial, Medicamentos, Notificaciones y Salir.

En la parte superior se muestra un encabezado compacto con las iniciales del usuario, su nombre, el rol y el botón de configuración para administrar usuarios si corresponde.

Si una pantalla es extensa, desplázate verticalmente con el dedo. La barra inferior permanece disponible para cambiar de módulo.

3. Inicio de sesión y recuperación de contraseña

3.1 Iniciar sesión

1
Escribí tu correo electrónico.
2
Escribí tu contraseña.
3

3.2 Recuperar contraseña

Desde la misma pantalla de acceso podés tocar "¿Olvidaste tu contraseña?" para abrir el formulario de recuperación.

SituaciónComportamiento
Correo inválido o no reconocidoEl sistema muestra el mensaje de error correspondiente sin salir de la pantalla.
Solicitud aceptadaSe informa que se envió un enlace al correo registrado.

4. Panel de inicio

Después de ingresar, el sistema abre el panel con tres métricas y el listado de medicamentos del día.

  • Personas registradas: total de adultos mayores cargados.
  • Con medicamentos hoy: personas con al menos una dosis programada.
  • Dosis programadas: total diario y, cuando aplica, las dosis del momento actual.
Para revisar todo el listado diario, deslízate hacia abajo. Cada tarjeta y cada bloque de paciente se acomoda al ancho del teléfono.

5. Adultos mayores

5.1 Lista y búsqueda

El módulo Adultos muestra un buscador superior y luego las tarjetas de cada persona con accesos a Ver y Eliminar.

5.2 Ver perfil

Al tocar "Ver" se abre el detalle del paciente con información personal, dirección, familiar solicitante y contacto de emergencia.

5.3 Nuevo registro

Desde "+ Nuevo registro" se abre un formulario vertical pensado para recorrer por secciones.

6. Historial de salud

En el módulo Historial primero se selecciona a la persona y luego se muestra la información clínica registrada.

Si tocas "Editar historial", la pantalla cambia a modo edición para actualizar padecimientos, lesiones, hábitos y operaciones.

7. Medicamentos

El módulo Medicamentos mantiene la misma lógica funcional que en escritorio, pero en celular la información se presenta en una sola columna para facilitar la lectura.

En la vista móvil es recomendable girar el teléfono solo si querés ver más contenido de una sola vez; no es obligatorio para usar el sistema.

8. Funciones administrativas

8.1 Notificaciones

Los usuarios con rol Administrador pueden abrir Notificaciones desde la barra inferior. Desde ahí pueden activar, limitar por días o apagar por completo el envío automático del correo diario de medicamentos.

8.2 Usuarios del sistema

El botón de engranaje del encabezado abre la administración de usuarios. En móvil este mantenimiento se presenta como modal sobre la pantalla actual.

9. Cierre de sesión

En celular, la acción Salir se encuentra en la barra inferior. Al tocarla, el sistema pide confirmación antes de cerrar la sesión.

1
Toca "Salir" en la barra inferior.
2
Confirma con "Sí, cerrar sesión".
3
El sistema vuelve a la pantalla de acceso.
